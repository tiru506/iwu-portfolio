1. The big picture

AI is the broad field. Machine learning is one approach within AI, and deep learning is a type of machine learning based on neural networks with multiple layers. Generative AI focuses on producing new content such as text, images, audio, or code.

Artificial IntelligenceSystems that perform tasks associated with intelligence, such as reasoning, planning, or perception.
Machine LearningMethods that learn patterns from examples and use them to make predictions or decisions.
Deep LearningMachine learning using neural networks with multiple processing layers.
Generative AIModels that generate new content. Many modern systems use deep learning, including transformers.
Key idea: An algorithm is a method or procedure. A model is the learned result after a learning algorithm is fitted to data. Not every AI system uses machine learning, and not every machine learning model is generative.

2. Algorithm framework

Explore ten commonly used algorithms and model families. Use the filters to compare learning style or application domain.

SupervisedUnsupervisedGenerative model familyApplication domain

1. Linear Regression

SupervisedTabular data

How it works: Fits a line or linear equation to estimate a continuous numerical value from input features.

Example: Predicting house prices from size, location, and number of bedrooms. Useful when the target is numerical and a linear relationship is a reasonable starting assumption.

2. Logistic Regression

SupervisedTabular data · NLP

How it works: Estimates the probability that an example belongs to a class, then applies a decision threshold or class-selection rule.

Example: Classifying transactions as potentially fraudulent or legitimate, or sorting messages into spam and not spam. A useful, interpretable baseline for classification.

3. Decision Tree

SupervisedTabular data · Vision

How it works: Learns feature-based questions that split examples into groups and end in a prediction.

Example: Predicting customer churn from account activity or classifying fruit from measured characteristics. Trees are explainable, but a very deep tree can overfit.

4. Random Forest

SupervisedTabular data · Vision

How it works: Combines predictions from many decision trees trained on varied samples and feature subsets.

Example: Predicting loan default risk or classifying features extracted from images. Combining trees often improves stability over a single tree.

5. Support Vector Machine (SVM)

SupervisedTabular · Vision · NLP

How it works: Finds a boundary that separates classes while seeking a large margin between them. Kernel methods can model more complex boundaries.

Example: Classifying documents using text features or recognizing objects from prepared image features. Performance depends on feature scaling and settings.

6. Neural Networks / Deep Learning

Often supervisedVision · NLP · Tabular

How it works: Layers of connected units learn representations by adjusting model weights during training. Neural networks can also use self-supervised or other training objectives.

Example: Image classification, speech recognition, or predicting outcomes from complex data. They can learn intricate patterns but may need substantial data and computing.

7. K-Means Clustering

UnsupervisedTabular data

How it works: Assigns examples to a chosen number of clusters by updating cluster centers and assigning each example to its nearest center.

Example: Grouping customers by purchasing behavior when no existing segment labels are available. Scaling and the number of clusters affect results.

8. Principal Component Analysis (PCA)

UnsupervisedTabular data

How it works: Transforms correlated numerical features into fewer dimensions that preserve as much variation as possible.

Example: Reducing many sensor measurements to a smaller set of components for visualization or modeling. New components can be harder to interpret.

9. Transformer Language Models (e.g., GPT)

Generative model familyNLP · Generative AI

How it works: Transformers use attention to model relationships among tokens. GPT-style models are trained to predict the next token and generate text step by step.

Example: Drafting summaries, answering questions, assisting with code, or preparing customer-support responses. Output should be checked for errors.

10. Diffusion Models

Generative model familyGenerative AI · Vision

How it works: Learns to reverse a noise-adding process, gradually turning noise into a sample that matches patterns learned during training.

Example: Generating illustrations or product concept images from text prompts. Quality depends on data, guidance, and model design.

Categories can overlap. Neural networks can support supervised prediction, self-supervised learning, or generation. Domain labels indicate common uses, not exclusive limits.

3. Four major application domains

The best approach depends on the input data, the goal, and how the output will be used.

📊

Tabular Data

Structured rows and columns such as sales, finance, customer, or healthcare records. Common choices include regression, decision trees, random forests, and clustering.

👁️

Computer Vision

Images and video. Deep neural networks, convolutional networks, vision transformers, and some SVM approaches support classification, detection, and segmentation.

💬

Natural Language Processing

Human language in text or speech. Models support translation, sentiment analysis, document classification, summarization, and question answering.

✨

Generative AI

Creates content such as text, images, audio, video, and code. Common families include transformer language models, diffusion models, and other generative neural networks.

4. Generative AI in practice

Generative AI creates new content rather than only assigning a label or predicting a fixed value.

From prompt to generated result

A typical workflow accepts an instruction or input, converts it into a representation the model can process, generates an output based on learned patterns, and returns content for a person to review.

Text generationDraft an email, summarize a report, explain a concept, or propose code with a language model.
Image generationCreate concept art or product mockups from a text description using an image-generation model.
Responsible useVerify important claims, protect confidential information, check for bias, and respect intellectual property.
Important limitation: Generative models produce plausible outputs, not guaranteed facts. Human review matters for accuracy, fairness, privacy, and consequential decisions.

6. Learning reflection

Reflection draft—personalize this to accurately describe your own learning experience before submitting.

Creating this framework helped me understand that machine learning algorithms are designed for different types of problems. Supervised learning uses labeled examples to make predictions, while unsupervised learning looks for patterns in data without predefined labels. I also learned that the same broad model family can be applied in different domains depending on the data and task.

The most interesting area for me is generative AI because models can create text, images, and other content from prompts. At the same time, these tools can make mistakes, so their outputs need to be reviewed carefully. In future data analytics projects, I will focus on selecting an approach that matches the problem, checking data quality, and evaluating results rather than choosing a model only because it is popular.
